# Seva Sphoorthi — Administrative Web Dashboard (`admin/`)

Dedicated web portal for coordinators and administrators, decoupled from the volunteer mobile experience.

## Modules Included (Pega Blueprint Aligned)
1. **Dashboard**: High-level KPIs, active rosters, today's camps, quick action queues.
2. **Volunteer Management**: Volunteer roster across 10,000+ records, search, filter by city/skills.
3. **Opportunity Management**: Drafting, quotas, skills criteria, category management.
4. **Approvals**: Publish approvals for drafts and urgent emergency relief drives.
5. **Background Verification**: Identity document verification (Aadhaar/Passport) and criminal disclosures audit.
6. **Scheduling**: Calendar and venue-based master shift views.
7. **Volunteer Assignment**: Automated Pega matching and manual coordinator assignment into opportunity quotas.
8. **Notifications**: 10k batch push broadcasting via Firebase Cloud Messaging (FCM).
9. **Reports**: Service hours auditing, 80G tax receipt summaries, engagement analytics.
10. **User Management**: Role assignment (VOLUNTEER, COORDINATOR, ADMIN) and access provisioning.
